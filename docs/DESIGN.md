# 设计系统 · 校园活动板

本文件锁定视觉规范。所有界面实现必须引用这里的令牌，**不允许出现令牌之外的临时字号、间距或颜色**——这是避免"字号忽大忽小、间距不齐、组件尺寸不统一"的根本手段。

## 一、设计目标

1. **信息层级清楚**：新生在 3 秒内判断"这条跟我有关吗、还来得及吗"。
2. **技术力可感知**：深色底 + 青/紫强调、微妙渐变与网格、克制的动效，而不是堆砌装饰。
3. **元素和谐**：字号、间距、圆角、阴影全部来自有限刻度，任何两个组件的对应属性必须同源。

## 二、色彩

深色主题，语义化命名。实现层使用 CSS 自定义属性，遵循"底色 → 表面 → 内容"三层结构。

| 令牌 | 用途 | 值（深色） |
| --- | --- | --- |
| `--bg` | 页面底色 | `#0b0f16` |
| `--bg-elev` | 抬升表面（卡片） | `#111826` |
| `--surface-2` | 次级表面（浮层、输入） | `#161f30` |
| `--border` | 分隔线 / 描边 | `rgba(255,255,255,.08)` |
| `--border-strong` | 强调描边 | `rgba(255,255,255,.16)` |
| `--text` | 主文本 | `#e8edf6` |
| `--text-muted` | 次要文本 | `#9aa7bd` |
| `--text-subtle` | 辅助说明 | `#6b7893` |
| `--accent` | 主强调（青） | `#38e0d0` |
| `--accent-2` | 次强调（紫） | `#8b7bff` |
| `--success` | 可报名 / 进行中 | `#3ddc97` |
| `--warning` | 即将截止 / 待确认 | `#ffb454` |
| `--danger` | 已截止 / 可疑内容 | `#ff6b81` |
| `--info` | 中性提示 | `#5aa9ff` |

状态色只用于**状态**，不用于装饰；强调色只用于**可交互与焦点**，不用于正文。

## 三、字体与字号阶梯

系统字体栈，避免外部字体加载失败导致的回退不一致：

```css
--font-sans: system-ui, -apple-system, "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif;
--font-mono: ui-monospace, "Cascadia Code", "JetBrains Mono", Consolas, monospace;
```

字号采用流体阶梯（`clamp`），**共 7 级，禁止取中间值**：

| 令牌 | 用途 | 值 |
| --- | --- | --- |
| `--fs-xs` | 标签、角标 | `clamp(12px, .74rem + .1vw, 13px)` |
| `--fs-sm` | 辅助说明、元信息 | `clamp(13px, .8rem + .1vw, 14px)` |
| `--fs-base` | 正文 | `clamp(14px, .86rem + .12vw, 15.5px)` |
| `--fs-lg` | 卡片标题 | `clamp(16px, .95rem + .2vw, 18px)` |
| `--fs-xl` | 区块标题 | `clamp(19px, 1.1rem + .3vw, 22px)` |
| `--fs-2xl` | 页面主标题 | `clamp(24px, 1.35rem + .6vw, 30px)` |
| `--fs-3xl` | 品牌字 | `clamp(30px, 1.7rem + .9vw, 40px)` |

行高统一：正文 `1.65`，标题 `1.3`，标签 `1.2`。
字重仅用 3 档：`400` 正文、`600` 强调、`700` 标题。
等宽字体**只用于数字与时间**（倒计时、日期、计数），保证对齐不跳动。

## 四、间距与尺寸刻度

间距基于 **4px** 刻度，对外只暴露 8 级：

`--sp-1: 4px` `--sp-2: 8px` `--sp-3: 12px` `--sp-4: 16px` `--sp-5: 24px` `--sp-6: 32px` `--sp-7: 48px` `--sp-8: 64px`

- 圆角：`--r-sm: 8px`、`--r-md: 12px`、`--r-lg: 16px`、`--r-xl: 22px`、`--r-pill: 999px`（**仅这 5 档**）
- 阴影：`--sh-1`（卡片静置）、`--sh-2`（悬停抬升）、`--sh-3`（浮层）——**共 3 档**
- 可点击元素最小高度 **40px**，主操作 **44px**；输入框统一 40px
- 内容最大宽度 `--w-max: 1200px`，正文段落最大宽度 `68ch`
- 层级（`z-index`）只允许：`--z-base:0`、`--z-sticky:10`、`--z-overlay:40`、`--z-modal:50`、`--z-toast:60`

## 五、布局规则

- 移动优先，断点只有 3 个：`640px`（单列→双列）、`900px`（侧栏出现）、`1200px`（三列上限）
- 卡片流使用 `grid` + `auto-fill/minmax`，保证元素等宽等高，不出现"卡片大小不一"
- 所有图标尺寸只有 3 档：`16px`（行内）、`20px`（按钮）、`24px`（区块）
- 状态徽标（badge）结构完全一致：`图标 + 文本`，同高 `24px`，同内边距 `--sp-2`

## 六、动效

- 时长只有 3 档：`--t-fast: 120ms`、`--t-base: 200ms`、`--t-slow: 320ms`
- 缓动：`--ease: cubic-bezier(.2,.8,.2,1)`
- 只动 `transform` 与 `opacity`；**遵循 `prefers-reduced-motion`**，用户关闭动效时全部降级为瞬时
- 交互反馈必须存在：悬停抬升、按下轻微缩放、焦点环清晰可见（键盘可用）

## 七、内容与呈现原则（产品层面强约束）

1. **不编造**：题目未提供的信息，字段为 `null` 并显式呈现"未提供 / 待确认"，绝不留空、绝不臆测。
2. **不替用户做决定**：可疑内容只做**标注与折叠**，永不删除，并给出判定理由与申诉说明。
3. **状态实时计算**：所有"已截止 / 进行中"由基准日期计算得出，禁止写死文案。
4. **来源必须可见**：任何一条信息都能一眼看出是学校、学院还是学生自发。
