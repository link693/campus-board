# 校园活动板 · Campus Board

面向在校学生、重点照顾新生体验的**校园活动与机会平台**。

> 本项目为珠海科技学院计算机协会软件部 2026 年秋季纳新第二轮考核（AI Agent 产品实战）作品。
> 题目提供的 26 条模拟校园信息全部落地于 `data/activities.json`，未编造任何题目未给出的事实。

---

## 解决什么问题

校园活动信息散落在不同来源（学校、学院、学生自发），质量与完整度参差不齐：

- 同一件事有两条通知，**后者修订前者**（时间、地点、名额变化），学生容易按旧信息行动；
- 报名截止、直播时间已经过去，列表里却看不出来；
- 关键信息缺失（费用、地点、截止时间）却没有任何提示；
- 学生自发信息里混着推广与可疑内容（"零门槛日结"、"加私人微信"），真假难辨；
- 新生不知道**哪些活动跟自己有关**（年级限制、是否需要基础、是否需要设备）。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 智能发现流 | 按状态分桶（进行中 / 即将截止 / 报名中 / 长期招募 / 已结束），支持关键词、来源、类别、适用对象筛选 |
| 详情与变更追踪 | 完整字段呈现 + 通知变更记录 + 关联条目（如"补充说明"与原文互链） |
| 新生模式 | 按年级与前置条件过滤，自动隐藏不适用项，突出"你还来得及" |
| 个人时间线 | 把报名截止与活动时间排成时间轴与倒计时，解决信息分散问题 |
| 开放发布 | 学生可自主发布招募与约球信息，进入正常使用流程，可编辑与撤回 |
| 本地持久化 | 收藏、报名状态、我的发布、筛选偏好刷新后保留 |

## 运行方式

直接在浏览器打开 `index.html` 即可（零构建、零依赖、无需服务器）。

```text
双击 index.html
```

## 技术形态

- **前端**：原生 HTML / CSS / JavaScript，零构建、零运行时依赖，静态托管友好；
- **Python 离线工具链**：`tools/` 下负责数据抽取、构建与校验，**不进入运行时**；
- **数据**：`data/activities.json` 为唯一数据源，构建为 `js/data.js` 供 `file://` 直接打开。

## 设计语言

统一的令牌化设计系统，避免字号、间距、组件尺寸不一致：

- **字体**：系统字体栈，字号采用流体阶梯（`clamp`），杜绝随机字号；
- **间距**：4px 基准刻度；
- **圆角与阴影**：有限层级，语义化命名；
- **色彩**：深色底 + 青/紫强调色，语义色（成功 / 警告 / 危险 / 中性）统一。

详细设计决策记录于 `docs/DESIGN.md`。
